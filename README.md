# esphome-halow

ESPHome external component for IEEE 802.11ah (Wi-Fi HaLow) using the Seeed XIAO HaLow Hat (WIO-WM6180) with Morse Micro MM6108 SoC.

## Hardware

- **MCU**: Seeed XIAO ESP32-S3
- **HaLow Module**: Seeed XIAO HaLow Hat (WIO-WM6180 / Morse Micro MM6108)
- **Access Point**: GL-iNet HaLowLink 2

## Status

🚧 **Early development** — Hardware verification phase.
